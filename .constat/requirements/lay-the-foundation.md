# Lay the foundation

## Problem

This phone app is the template's own first commit and nothing in it belongs to anybody yet: it has a name nobody chose, a screen nobody asked for, and no proof that the pathway from an ask to a witnessed attempt works at all on this copy.

## Description

Make the first thing that is yours. Name the product where it says its own name, and let the attempt that does it go the whole way round: an agent writes it, CI runs the checks the template already carries and publishes what ran, and what it did lands on the record beside this requirement. Nothing here is scaffolding to delete later — it is the first witnessed change.

## Acceptance criteria

- A fresh checkout installs and runs its tests in CI — the check foundation > installs and tests
- The app starts and shows its name on its first screen — the check foundation > first screen
- DoneMark reads the repository as ready: evidence, runner, and a Run button — a fact from the reporter, not a check
